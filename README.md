# Rühm 16 - Knightid

See leht tutvustab meie TalTechi kursuse „Kasutajakogemus ja Liidesed” projekti. Uurisime tudengite kogemust TalTechi digiteenustega ja panime tulemused siia kokku.

Lehe nägemiseks ava `index.html` brauseris.

## GitHub Pages

Repo seadetes ava **Settings → Pages**. Vali avaldamiseks haru `main` ja kaust `/(root)`, siis vajuta **Save**. Leht on tavaline HTML, CSS ja JavaScript ning eraldi build'i pole vaja.
